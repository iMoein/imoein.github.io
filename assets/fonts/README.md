# Self-hosted open fonts

Inter and Vazirmatn are retrieved unchanged from the Google Fonts CSS response for weights 400, 500, 600, 700, 800, display=swap (2026-11-17). Original Unicode ranges and weight declarations are preserved. Font files are distributed under their respective SIL Open Font License; see the included OFL texts. Source URLs and SHA-256 checksums are recorded in sources.json.

This bundle replaces the remote stylesheet only on the six pages which previously requested it. The existing IRANSansX font is unrelated and has not been modified or redistributed as a new font.
